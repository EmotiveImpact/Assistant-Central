# Parlu SDK

The open-source toolkit for connecting agents and apps to Parlu. Apache-2.0.

- [Python](python/README.md): `pip install ./sdk/python` (add `[mcp]` for the MCP client)
- Any other language: the [plain web API](python/README.md#plain-web-api-any-language) is one JSON POST per call.
- [ChatGPT and Dots](CHATGPT.md): connecting an assistant that lives in ChatGPT.

This folder is self-contained so it can move to its own repository. It does
not import any Parlu app code.
