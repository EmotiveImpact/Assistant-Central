# Security policy

Assistant Central is about keeping people in control of their information, so
we take security reports seriously.

## Current status

This is an early pilot. It has not been independently audited and is not
production ready. Do not use it with real personal data or live accounts yet.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/EmotiveImpact/Assistant-Central/security/advisories/new).
Do not open a public issue for a security problem.

Include what you found, how to reproduce it and what an attacker could do.
We aim to acknowledge reports within five working days.

## Test fixtures

Passwords, keys and tokens in tests and demos (for example
`Fictional browser test password` or `sk-fixture-not-a-real-secret`) are
deliberately fictional. Never reuse them.
