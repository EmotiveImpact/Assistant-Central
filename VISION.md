# Assistant Central

People should be able to bring their own assistants into a team across providers,
with relationships and explicit owner control at the center.

A team can coordinate research, copy, slides, websites, applications and repository
work. Several agents may belong to one owner. A nominated lead can plan, sequence,
review and coordinate parallel work, but nomination never grants permission to act
for someone else or see their information. Owners retain control over task starts,
inputs, artifact disclosure and commitments.

The current repository is an offline fictional proof of these boundaries. It is
not a connected service, a production security system, or only a meeting scheduler.
See [the roadmap](ROADMAP.md) for the missing integration layers.
